# AMKSTUDY

GitHub-ready static PWA.

## Main behavior
- Chapters are fixed notes; users add only topics inside chapters.
- Topic completion is tracked per topic.
- Focus sessions can be linked to a topic.
- Revision repeats forever: 1 → 4 → 7 → 15 → 30 → 1 → 4 → …
- Individual topics can be deleted from the subject topic list.
- Individual revision entries can be deleted.
- Individual session-log entries can be deleted.
- Timer and revision progress bars are included.
- Startup sound is a short waterdrop-style UI sound.
- Voice announcements select an English voice using a male-voice preference heuristic where the device exposes suitable voices.

## Deploy
Upload all files in this folder to a GitHub repository and enable GitHub Pages.
